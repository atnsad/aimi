## 📖 معرفی
این پروژه با هدف ارتقای سطح دقت (Accuracy) و سرعت عمل (Reflex) توسعه یافته است. در دنیای رقابتی بازی‌ها، میلی‌ثانیه‌ها تعیین‌کننده هستند؛ این بازی، محیطی کنترل‌شده برای تمرین این مهارت‌ها فراهم می‌کند.

## 🕹 نحوه شروع
پس از اجرای بازی، با رابط کاربری ساده‌ای روبرو می‌شوید که شامل بخش‌های زیر است:

* **آموزش و توضیحات:** دسترسی به راهنمای جامع بازی (همین صفحه).
* **بخش‌های تمرینی:** شامل ۵ دسته‌بندی مختلف برای تمرین.
    * *نکته:* هر چه شماره‌ی مرحله بالاتر باشد، چالش سخت‌تر و سرعت مورد نیاز بیشتر خواهد بود.

## 🎮 گیم‌پلی
روند بازی ساده اما بی‌رحم است:
1. **تایمر ۳ ثانیه‌ای:** آماده‌سازی پیش از شروع بازی.
2. **شکار دایره‌ها:** دایره‌های توخالی در زمان‌ها و مکان‌های تصادفی ظاهر می‌شوند.
3. **واکنش سریع:** باید قبل از محو شدن کامل دایره، روی آن کلیک کنید.
4. **Game Over:** اگر سرعت عمل شما کافی نباشد و دایره ناپدید شود، بازی به پایان رسیده و امتیاز نهایی به شما نمایش داده می‌شود.

## 🚀 ویژگی‌های کلیدی
- **مکانیزم تصادفی:** مکان و زمان ظهور دایره‌ها کاملاً متغیر است تا هیچ الگوی قابل پیش‌بینی وجود نداشته باشد.
- **سختی پلکانی:** ۵ سطح دشواری برای سنجش میزان پیشرفت شما.
- **تمرکز بر پرفورمنس:** طراحی سبک و بهینه برای جلوگیری از هرگونه لگ (Lag) که دقت شما را مختل کند.
